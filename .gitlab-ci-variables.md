# Variables d'environnement GitLab CI/CD

## Variables requises dans GitLab

### 1. Azure Container Registry
- `ACR_USERNAME` : Nom d'utilisateur du registry Azure
- `ACR_PASSWORD` : Mot de passe du registry Azure

### 2. Azure Service Principal (Staging)
- `AZURE_CLIENT_ID` : ID du service principal Azure
- `AZURE_CLIENT_SECRET` : Secret du service principal Azure
- `AZURE_TENANT_ID` : ID du tenant Azure

### 3. Chaînes de connexion Staging
- `STAGING_CONNECTION_STRING` : Chaîne de connexion PostgreSQL staging
- `STAGING_REDIS_CONNECTION_STRING` : Chaîne de connexion Redis staging
- `STAGING_JWT_SECRET` : Clé secrète JWT pour staging
- `STAGING_APPINSIGHTS_KEY` : Clé Application Insights staging
- `STAGING_NEXTAUTH_SECRET` : Secret NextAuth pour staging

### 4. Chaînes de connexion Production
- `PRODUCTION_CONNECTION_STRING` : Chaîne de connexion PostgreSQL production
- `PRODUCTION_REDIS_CONNECTION_STRING` : Chaîne de connexion Redis production
- `PRODUCTION_JWT_SECRET` : Clé secrète JWT pour production
- `PRODUCTION_APPINSIGHTS_KEY` : Clé Application Insights production
- `PRODUCTION_NEXTAUTH_SECRET` : Secret NextAuth pour production

## Configuration dans GitLab

1. Allez dans **Settings > CI/CD > Variables**
2. Ajoutez chaque variable avec :
   - **Key** : Le nom de la variable
   - **Value** : La valeur (masquée pour les secrets)
   - **Type** : Variable (ou File pour les certificats)
   - **Environment scope** : All (ou spécifique à l'environnement)
   - **Protect variable** : ✅ (pour les secrets)
   - **Mask variable** : ✅ (pour les secrets)

## Variables optionnelles

### Notifications
- `SLACK_WEBHOOK_URL` : URL du webhook Slack pour les notifications
- `TEAMS_WEBHOOK_URL` : URL du webhook Teams pour les notifications

### Cache
- `NUGET_CACHE_KEY` : Clé de cache NuGet (générée automatiquement)
- `NODE_CACHE_KEY` : Clé de cache Node.js (générée automatiquement)
