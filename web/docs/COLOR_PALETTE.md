# Palette de Couleurs - Lead Tracker

## Couleurs Principales

### Couleur Primaire : Vert Émeraude
- **Hex Code:** `#10B981`
- **Classe Tailwind:** `brand-500`
- **Utilisation:** 
  - Logo et icônes principales
  - Boutons principaux
  - Liens et accents
  - États de focus
  - Éléments actifs de navigation
  
- **Palette complète (Tailwind):** brand-50 à brand-950

### Couleur Secondaire : Violet/Lavande
- **Hex Code:** `#D2CAEC`
- **Classe Tailwind:** `secondary-300`
- **Utilisation:**
  - Boutons secondaires
  - Badges et indicateurs alternatifs
  - Accents complémentaires
  - États de hover pour navigation inactive
  
- **Palette complète (Tailwind):** secondary-50 à secondary-950

## Caractéristiques

- **Vert Émeraude:** Professionnel, moderne, apaisant
- **Violet/Lavande:** Crée une harmonie élégante avec le vert émeraude primaire

## Application dans le Code

### Navigation
- Item actif: `text-brand-600 bg-brand-50`
- Item inactif au hover: `hover:bg-secondary-50`
- Logo: `text-brand-500`

### Boutons
- Bouton primaire: `bg-brand-500 hover:bg-brand-600`
- Bouton secondaire: `bg-secondary-300 hover:bg-secondary-400`
