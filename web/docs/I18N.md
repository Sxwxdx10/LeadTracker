# 🌍 Internationalisation (i18n) - Lead Tracker

## 📋 Vue d'ensemble

Le système d'internationalisation permet de supporter plusieurs langues dans l'application Lead Tracker. Actuellement, les langues supportées sont :
- 🇫🇷 **Français** (par défaut)
- 🇬🇧 **Anglais**

## 🏗️ Architecture

### Structure des fichiers

```
web/src/
├── contexts/
│   └── LanguageContext.tsx    # Contexte de gestion de la langue
├── hooks/
│   └── useTranslation.ts      # Hook pour les traductions
├── locales/
│   ├── fr.json               # Traductions françaises
│   └── en.json               # Traductions anglaises
└── components/
    └── LanguageSelector.tsx   # Composant de sélection de langue
```

### Composants

1. **LanguageContext** - Gère la langue courante
2. **useTranslation** - Hook pour accéder aux traductions
3. **LanguageSelector** - UI pour changer de langue

## 🚀 Guide de démarrage rapide

### 1. Setup dans votre application

Envelopper votre application avec le `LanguageProvider` :

```tsx
// app/layout.tsx ou providers.tsx
import { LanguageProvider } from '@/contexts/LanguageContext';

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        <LanguageProvider defaultLanguage="fr">
          {children}
        </LanguageProvider>
      </body>
    </html>
  );
}
```

### 2. Utiliser les traductions dans un composant

```tsx
import { useTranslation } from '@/hooks/useTranslation';

function MyComponent() {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t('common.welcome')}</h1>
      <button>{t('common.save')}</button>
      <p>{t('leads.noLeads')}</p>
    </div>
  );
}
```

### 3. Ajouter le sélecteur de langue

```tsx
import { LanguageSelector } from '@/components/LanguageSelector';

function Header() {
  return (
    <header>
      <nav>
        {/* Contenu de navigation */}
        <LanguageSelector />
      </nav>
    </header>
  );
}
```

## 📖 Documentation détaillée

### Hook useTranslation

#### Fonction `t(key, params?)`

Récupère une traduction par sa clé.

```tsx
const { t } = useTranslation();

// Simple
t('common.save')  // → "Enregistrer" ou "Save"

// Avec paramètres
t('forms.validation.minLength', { min: 8 })
// → "Minimum 8 caractères requis" ou "Minimum 8 characters required"

// Clés imbriquées
t('leads.stages.prospect')  // → "Prospect"
t('users.roles.admin')      // → "Administrateur" ou "Administrator"
```

#### Fonction `tc(key, count, params?)`

Traduction avec pluralisation.

```tsx
const { tc } = useTranslation();

tc('time.minutes_ago', 1)  // → "il y a 1 minute"
tc('time.minutes_ago', 5)  // → "il y a 5 minutes"

tc('time.hours_ago', 1)    // → "il y a 1 heure"
tc('time.hours_ago', 3)    // → "il y a 3 heures"
```

#### Propriété `language`

Accéder à la langue courante.

```tsx
const { t, language } = useTranslation();

console.log(language); // "fr" ou "en"
```

### Hook useLanguage

Accéder et modifier la langue.

```tsx
import { useLanguage } from '@/contexts/LanguageContext';

function MyComponent() {
  const { language, setLanguage, availableLanguages } = useLanguage();

  return (
    <div>
      <p>Langue courante : {language}</p>
      <button onClick={() => setLanguage('en')}>
        Switch to English
      </button>
      <p>Langues disponibles : {availableLanguages.join(', ')}</p>
    </div>
  );
}
```

### Composant LanguageSelector

#### Variantes

**Dropdown (défaut)**

```tsx
<LanguageSelector />
// Dropdown avec globe, drapeau et label
```

**Inline**

```tsx
<LanguageSelector 
  variant="inline"
  showLabel={true}
  showFlag={true}
/>
// Boutons côte à côte
```

**Compact**

```tsx
import { LanguageSelectorCompact } from '@/components/LanguageSelector';

<LanguageSelectorCompact />
// Petit bouton avec drapeau uniquement
```

**Mobile**

```tsx
import { LanguageSelectorMobile } from '@/components/LanguageSelector';

<LanguageSelectorMobile />
// Version optimisée pour mobile
```

#### Props

| Prop | Type | Défaut | Description |
|------|------|--------|-------------|
| `variant` | `'dropdown' \| 'inline'` | `'dropdown'` | Style du sélecteur |
| `showLabel` | `boolean` | `true` | Afficher le nom de la langue |
| `showFlag` | `boolean` | `true` | Afficher le drapeau |
| `className` | `string` | - | Classes CSS additionnelles |

## 🎯 Patterns courants

### Formulaires

```tsx
function LoginForm() {
  const { t } = useTranslation();

  return (
    <form>
      <label>{t('auth.email')}</label>
      <input 
        type="email" 
        placeholder={t('forms.placeholders.enterText')}
      />
      
      <label>{t('auth.password')}</label>
      <input type="password" />
      
      {error && <p>{t('auth.invalidCredentials')}</p>}
      
      <button>{t('auth.login')}</button>
    </form>
  );
}
```

### Messages d'erreur

```tsx
function MyComponent() {
  const { t } = useTranslation();
  const [error, setError] = useState('');

  const handleSubmit = async () => {
    try {
      await api.submit();
      toast.success(t('common.success'));
    } catch (err) {
      setError(t('errors.generic'));
    }
  };

  return (
    <>
      {error && <div role="alert">{error}</div>}
      <button onClick={handleSubmit}>
        {t('common.submit')}
      </button>
    </>
  );
}
```

### Listes avec traductions

```tsx
function StatusSelect() {
  const { t } = useTranslation();
  
  const statuses = [
    { value: 'prospect', label: t('leads.stages.prospect') },
    { value: 'qualified', label: t('leads.stages.qualified') },
    { value: 'proposal', label: t('leads.stages.proposal') },
  ];

  return (
    <select>
      {statuses.map(status => (
        <option key={status.value} value={status.value}>
          {status.label}
        </option>
      ))}
    </select>
  );
}
```

### Navigation

```tsx
function Navbar() {
  const { t } = useTranslation();
  
  const navItems = [
    { href: '/', label: t('navigation.home') },
    { href: '/leads', label: t('navigation.leads') },
    { href: '/analytics', label: t('navigation.analytics') },
  ];

  return (
    <nav>
      {navItems.map(item => (
        <a key={item.href} href={item.href}>
          {item.label}
        </a>
      ))}
      <LanguageSelector variant="inline" />
    </nav>
  );
}
```

### Traductions avec paramètres

```tsx
function ValidationMessage({ minLength }: { minLength: number }) {
  const { t } = useTranslation();
  
  return (
    <p className="text-red-600">
      {t('forms.validation.minLength', { min: minLength })}
    </p>
  );
}
```

### Dates relatives

```tsx
function TimeAgo({ date }: { date: Date }) {
  const { tc } = useTranslation();
  
  const minutesAgo = Math.floor((Date.now() - date.getTime()) / 60000);
  
  if (minutesAgo < 1) {
    return <span>{t('time.just_now')}</span>;
  }
  
  if (minutesAgo < 60) {
    return <span>{tc('time.minutes_ago', minutesAgo)}</span>;
  }
  
  const hoursAgo = Math.floor(minutesAgo / 60);
  return <span>{tc('time.hours_ago', hoursAgo)}</span>;
}
```

## 🛠️ Fonctions utilitaires

### translate()

Obtenir une traduction sans hook (hors composants).

```tsx
import { translate } from '@/hooks/useTranslation';

// Dans une fonction utilitaire
export function formatStatus(status: string): string {
  return translate(`leads.stages.${status}`, 'fr');
}

// Dans un fichier de configuration
export const config = {
  title: translate('app.title', 'en'),
};
```

### hasTranslation()

Vérifier si une clé existe.

```tsx
import { hasTranslation } from '@/hooks/useTranslation';

if (hasTranslation('myFeature.newKey', 'fr')) {
  // La clé existe
}
```

### validateTranslations()

Valider que toutes les clés existent dans les deux langues.

```tsx
import { validateTranslations } from '@/hooks/useTranslation';

// En développement
const missing = validateTranslations();
console.log('Missing in FR:', missing.fr);
console.log('Missing in EN:', missing.en);
```

## 🌐 Ajouter une nouvelle langue

### 1. Créer le fichier de traductions

```bash
cp web/src/locales/fr.json web/src/locales/es.json
# Traduire toutes les valeurs en espagnol
```

### 2. Mettre à jour le type Language

```tsx
// contexts/LanguageContext.tsx
export type Language = 'fr' | 'en' | 'es';
```

### 3. Importer les traductions

```tsx
// hooks/useTranslation.ts
import esTranslations from '@/locales/es.json';

const translations = {
  fr: frTranslations,
  en: enTranslations,
  es: esTranslations,
};
```

### 4. Ajouter le label et le drapeau

```tsx
// components/LanguageSelector.tsx
const languageLabels: Record<Language, string> = {
  fr: 'Français',
  en: 'English',
  es: 'Español',
};

const languageFlags: Record<Language, string> = {
  fr: '🇫🇷',
  en: '🇬🇧',
  es: '🇪🇸',
};
```

## 🧪 Tests

### Test d'une traduction

```tsx
import { render, screen } from '@testing-library/react';
import { LanguageProvider } from '@/contexts/LanguageContext';

test('displays translated text', () => {
  render(
    <LanguageProvider defaultLanguage="fr">
      <MyComponent />
    </LanguageProvider>
  );
  
  expect(screen.getByText('Enregistrer')).toBeInTheDocument();
});
```

### Test du changement de langue

```tsx
import { renderHook, act } from '@testing-library/react';
import { useLanguage } from '@/contexts/LanguageContext';

test('changes language', () => {
  const { result } = renderHook(() => useLanguage(), {
    wrapper: LanguageProvider,
  });
  
  expect(result.current.language).toBe('fr');
  
  act(() => {
    result.current.setLanguage('en');
  });
  
  expect(result.current.language).toBe('en');
});
```

## 💡 Bonnes pratiques

### ✅ À faire

1. **Toujours utiliser le hook** pour accéder aux traductions
   ```tsx
   const { t } = useTranslation();
   return <h1>{t('title')}</h1>;
   ```

2. **Grouper les traductions par feature**
   ```json
   {
     "leads": { ... },
     "tasks": { ... }
   }
   ```

3. **Utiliser des clés descriptives**
   ```tsx
   // ✅ Bon
   t('leads.actions.sendEmail')
   
   // ❌ Mauvais
   t('btn1')
   ```

4. **Garder la même structure dans toutes les langues**

### ❌ À éviter

1. **Hardcoder du texte**
   ```tsx
   // ❌ Mauvais
   <button>Enregistrer</button>
   
   // ✅ Bon
   <button>{t('common.save')}</button>
   ```

2. **Concaténer des traductions**
   ```tsx
   // ❌ Mauvais
   `${t('hello')} ${name}`
   
   // ✅ Bon
   t('greeting', { name })
   // JSON: "greeting": "Hello {{name}}"
   ```

3. **Oublier de traduire en anglais**
   ```
   Toujours mettre à jour les deux fichiers !
   ```

## 📊 Clés de traduction disponibles

Catégories principales :

- `common.*` - Éléments communs (boutons, actions)
- `navigation.*` - Navigation
- `auth.*` - Authentification
- `leads.*` - Gestion des prospects
- `tasks.*` - Gestion des tâches
- `users.*` - Gestion des utilisateurs
- `analytics.*` - Analytique et rapports
- `settings.*` - Paramètres
- `forms.*` - Formulaires et validation
- `errors.*` - Messages d'erreur
- `date.*` - Dates
- `time.*` - Temps relatif

Voir les fichiers `locales/*.json` pour la liste complète.
