# Variables d'environnement GitLab CI/CD - Version Docker Hub

## Variables requises dans GitLab (Docker Hub)

### 1. Docker Hub (Remplace Azure Container Registry)
- `DOCKERHUB_USERNAME` : Votre nom d'utilisateur Docker Hub
- `DOCKERHUB_PASSWORD` : Votre mot de passe Docker Hub (ou token d'accès)

### 2. Variables optionnelles pour les tests
- `TEST_DATABASE_URL` : URL de base de données pour les tests (optionnel)
- `TEST_REDIS_URL` : URL Redis pour les tests (optionnel)

## Configuration dans GitLab

1. Allez dans **Settings > CI/CD > Variables**
2. Ajoutez chaque variable avec :
   - **Key** : Le nom de la variable
   - **Value** : La valeur (masquée pour les secrets)
   - **Type** : Variable
   - **Environment scope** : All
   - **Protect variable** : ✅ (pour les secrets)
   - **Mask variable** : ✅ (pour les secrets)

## Variables requises (2 seulement !)

```
Key: DOCKERHUB_USERNAME
Value: [votre nom d'utilisateur Docker Hub]
✅ Mask variable
✅ Protect variable
```

```
Key: DOCKERHUB_PASSWORD
Value: [votre mot de passe Docker Hub ou token d'accès]
✅ Mask variable
✅ Protect variable
```

## Comment obtenir ces valeurs ?

### 1. Créer un compte Docker Hub
1. Allez sur https://hub.docker.com/
2. Cliquez sur "Sign Up"
3. Créez un compte gratuit
4. Confirmez votre email

### 2. Créer un token d'accès (Recommandé)
1. Allez dans Account Settings > Security
2. Cliquez sur "New Access Token"
3. Donnez un nom (ex: "GitLab CI")
4. Copiez le token généré

### 3. Utiliser le token
- **DOCKERHUB_USERNAME** : Votre nom d'utilisateur Docker Hub
- **DOCKERHUB_PASSWORD** : Le token d'accès (pas votre mot de passe)

## Migration depuis Azure

Si vous voulez passer d'Azure à Docker Hub :

1. **Remplacez** `.gitlab-ci.yml` par `.gitlab-ci-dockerhub.yml`
2. **Supprimez** les variables Azure dans GitLab
3. **Ajoutez** les variables Docker Hub
4. **Testez** le pipeline
